# pcpa-folha-suple

**Protótipo** de aplicação para cálculo e geração de **Folhas Suplementares** (13º proporcional e férias proporcionais) para a Polícia Civil do Estado do Pará — objetivo: substituir planilhas Excel por um motor de cálculo auditável, importador de modelos e exportador de leiautes compatíveis com eSocial.

---

## Visão geral
**O que faz:** importa modelos de folha (PDF/XLSX), normaliza rubricas, executa o motor de cálculo (13º proporcional, férias proporcionais, adicional 1/3, descontos como FINANPREV/INSS/IRRF), gera preview para conferência e exporta resultados em JSON/CSV/PDF e leiaute eSocial.  
**Escopo inicial:** motor de cálculo, importador básico, UI de revisão, API REST, testes com exemplos reais.
