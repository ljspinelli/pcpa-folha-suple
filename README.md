# pcpa-folha-suple

Protótipo para substituir planilhas Excel usadas no cálculo de Folhas Suplementares (13º proporcional e férias proporcionais) da Polícia Civil do Estado do Pará.

## Objetivo
Criar uma aplicação web simples que:
- recebe dados digitados manualmente (sem importar PDF)
- calcula 13º proporcional
- calcula férias proporcionais e 1/3 constitucional
- exibe os resultados em uma interface clara
- gera um resumo para conferência
